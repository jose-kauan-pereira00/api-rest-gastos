# Aula 006

## Estrutura do Projeto

* Config - configurações
* Controller - onde ficar os controladores
* Domain - onde fica os models, regras de negocios, serviços de domínio, etc
* DTO - guarda os dtos
* Handler - guardar os manipuladores de exeção
* Security - Tudo relacionado a segurança do projeto- usando jwt
* Common -  os arquivos comuns, que podem ser usados em qualquer lugar do projetos
